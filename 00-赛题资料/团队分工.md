# 团队分工

> 项目：第四届世界科学智能大赛古文字识别赛道 — 少样本跨域古文字识别
>
> 建立日期：2026-05-20
>
> 适用范围：三人参赛队伍

---

## 1. 队伍定位

本队最大优势是同时具备**工程能力**与**古文字领域知识**。比赛能否拉开差距，取决于能否把领域知识转化为模型可用的输入（数据观察、错例归因、形近字字典、释读复核）。

因此：

- 计算机背景成员负责工程链路，独立保障数据处理、模型训练与提交可运行。
- 历史背景成员负责领域工作，全部产出以**领域专家视角**为模型决策提供依据。
- 两侧职责互不替代，任一方延期都会阻塞整体进度。

---

## 2. 角色

| 角色             | 简称 | 背景   | 核心职责                             |
| ---------------- | ---- | ------ | ------------------------------------ |
| 工程负责人       | E    | 计算机 | 数据下载、训练、推理、提交、实验记录 |
| 数据领域专家     | D    | 历史   | 数据样本观察、错例归因、形近字整理   |
| 文献与报告负责人 | R    | 历史   | 文献调研、资源搜集、报告与对外材料   |

---

## 3. 共同工作原则

1. D 与 R **不参与编程**，所需工具仅限：Excel / Word / 飞书或腾讯文档 / PDF 阅读器。
2. 所有任务以**周日 22:00**为统一截止时间。
3. 未能按时完成的任务，应在截止前 24 小时内于团队群通报，并给出新时间。
4. 遇到术语或概念不清，第一时间在团队群提问，或先咨询 AI 工具，不要长时间自行卡住。
5. 任何对外材料（汇报、PPT、报告）以本队共享文档为唯一版本。

---

## 4. 角色 D：数据领域专家

### 4.1 第一周（2026-05-20 至 2026-05-24）

| 编号 | 任务              | 执行方式                                                            | 交付物          |
| ---- | ----------------- | ------------------------------------------------------------------- | --------------- |
| D1-1 | 等 E 完成数据抽样 | E 将在数据到位后从训练集随机抽取约 100 张样本发送至团队群           | 无              |
| D1-2 | 载体分类统计      | 将 100 张样本按"拓片 / 扫描 / 手写 / 合成 / 其他"分类，记录大致比例 | Excel 表格      |
| D1-3 | 形近字对整理      | 凭领域直觉挑出至少 10 组易混淆字对，每组配两张代表图像              | Word 或共享文档 |
| D1-4 | 标注质量观察      | 浏览过程中标记疑似错标样本，单独记录一栏                            | 同上            |

### 4.2 第二周（2026-05-25 至 2026-05-31）

| 编号 | 任务         | 执行方式                                                      | 交付物         |
| ---- | ------------ | ------------------------------------------------------------- | -------------- |
| D2-1 | 错例样本接收 | E 将基线模型预测错误的约 100 张图像整理后发送                 | 无             |
| D2-2 | 错例五类归因 | 每张图归入：①形近混淆 ②字形残缺 ③拓片噪声 ④写法变体 ⑤标注错误 | Excel 表格     |
| D2-3 | 优先级建议   | 统计各类错例占比，给出"下一步应优先攻克的错误类型"建议        | 团队群书面意见 |

### 4.3 第三周及以后

- 维护**形近字对字典**：在测试集范围内整理可能混淆的字对，供后续训练策略使用。
- 对模型输出进行抽样人工复审，标记明显不合理的预测。
- 协助 R 撰写报告中的"数据特征"与"误差分析"章节。

## 5. 角色 R：文献与报告负责人

### 5.1 第一周（2026-05-20 至 2026-05-24）

| 编号 | 任务             | 执行方式                                                                                         | 交付物              |
| ---- | ---------------- | ------------------------------------------------------------------------------------------------ | ------------------- |
| R1-1 | 文献调研（3 篇） | ①古文字识别或历史文献 OCR 综述 1 篇；②少样本图像识别入门或综述 1 篇；③往届类似比赛 top 方案 1 篇 | PDF 文件 + 引用信息 |
| R1-2 | 每篇 200 字摘要  | 摘要重点回答：本文方法或结论对本项目有哪些可借鉴之处                                             | 共享文档            |
| R1-3 | 建立共享文档     | 新建腾讯文档或飞书文档作为团队知识库入口                                                         | 文档链接            |

> 检索建议来源：知网、Google Scholar、天池 / Kaggle 复盘、CCF-CV 推荐列表。
>
> 阅读方式：摘要 + 结论 + 关键图表为主，不要求深入复现。

### 5.2 第二周（2026-05-25 至 2026-05-31）

| 编号 | 任务           | 执行方式                                                                                                     | 交付物   |
| ---- | -------------- | ------------------------------------------------------------------------------------------------------------ | -------- |
| R2-1 | 历届方案分析   | 选取 3 个相关比赛 top 方案（往届 SAIL、阿里天池 OCR、Kaggle 历史文献等），归纳模型结构、数据增强、关键 trick | 共享文档 |
| R2-2 | 古文字资源清单 | 整理可用字典与字库（如汉典、国学大师、殷契文渊、相关学术数据库），并标注访问方式                             | 共享文档 |
| R2-3 | 报告框架搭建   | 按"背景 / 数据 / 方法 / 实验 / 结论"五章建立空白骨架，后续逐步填充                                           | 报告草稿 |

### 5.3 第三周及以后

- 维护团队周报，每周日基于 E 与 D 的产出整理一段进度同步，发送至团队群并抄送指导老师。
- 撰写报告正文中"背景""相关工作""数据介绍"三章初稿，无需等待实验完成。
- 视赛事要求准备答辩 PPT 框架。

### 6.1 第一周（2026-05-20 至 2026-05-24）

| ---------- | --------------------------------------------------------------------------------------------- |

- 维护 `03-实验/JOURNAL.md` 与 `03-实验/runs.jsonl`。

---

## 8. 例会标准议程

每次例会按以下五项推进：

1. 上周任务完成情况盘点。
2. 当前阻塞项与所需资源。
3. 关键决策（模型方向、提交策略、资源申请等）。
4. 下周任务认领与截止时间。
5. 责任与节点书面化，记录至共享文档。

---

## 9. 首周收尾确认

第一周例会结束时，每位成员应当当面或在共享文档中明确：

- 本周认领任务编号与内容；
- 完成时间；
- 完成后提交至何处。

未完成上述确认的任务视为未认领。
