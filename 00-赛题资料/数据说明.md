## 首轮数据检查清单

- [ ] 文件是否能完整解压；
- [ ] 图片是否能被 PIL / OpenCV 正常读取；
- [ ] 标签文件是否有缺失值；
- [ ] 图片数量与标签数量是否一致；
- [ ] 类别数、每类样本数、长尾程度；
- [ ] 图片尺寸、通道数、格式分布；
- [ ] 是否存在重复图片或近重复图片；
- [ ] 是否能从文件名或目录名看出 domain 信息。

---

## 验证集切分原则

第一版先保守：

1. 如果赛方给了官方验证集，优先使用官方划分。
2. 如果有 domain 字段，至少保留一个跨域验证切分。
3. 如果没有 domain 字段，先做 stratified split（按类别分层切分），再用图像统计特征检查分布差异。
4. 不把测试集信息泄漏进训练过程。
