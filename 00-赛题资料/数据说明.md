## 标签格式

| 字段 | 含义 | 示例 |
|---|---|---|
| XML encoding | XML 文件声明编码 | `encoding="utf-16"` |
| page id | 图像 ID | `sample.png` |
| page width/height | XML 标注坐标系尺寸 | `width="100" height="80"` |
| char position | 单字位置，可能是多边形或矩形 | `x,y;x,y;...` 或 `x1,y1,x2,y2` |
| char text | 类别/字符标签 | `大`、`𢭃` 等 |

首轮解析统计：

| 项 | 数量 |
|---|---:|
| char boxes | 61,271 |
| 有效标签实例 | 61,248 |
| 有效标签类别数 | 4,114 |

| 无效标签：空字符串 | 3 |
| 每个 XML 字数 | min 1 / max 155 / avg 9.82 |

坐标与图片注意事项：

1. XML 坐标系尺寸和真实图片尺寸不一定一致，需要按比例映射。
2. 有 1,631 个样本存在 XML 宽高与图片宽高不一致；其中一部分是缩放，一部分是宽高交换。
3. 对宽高交换样本，当前脚本使用自动推断：优先比较 direct 与 clockwise rotation 的比例一致性，必要时按顺时针旋转映射坐标。
4. 唯一 TIF 图片尺寸较大，PIL 读取时需要关闭 `Image.MAX_IMAGE_PIXELS` 限制。

## 标签编码与异常值规则

> 2026-05-21 根据赛题通知补充。

1. 部分 XML 标签中的古文字可能在 Sublime、记事本或浏览器中显示为乱码、方块或空白，这通常是本地字体/编辑器缺少对应古文字字形导致，不代表标签错误。
2. 只要程序能把标签解析为一个有效 Unicode 码点，即可视为正常标签并用于训练。
3. `ZH-` 开头的字符串、`None` 等属于标注时无法映射到标准 Unicode 的占位符或异常值，不是有效 Unicode 码点，应在构建训练集时过滤。
4. XML 读取应尊重文件声明编码（当前训练 XML 为 UTF-16）；最终提交文件 `prediction.json` 必须使用 UTF-8。
5. 判断标签是否可用，以程序解码结果为准，不以屏幕显示是否乱码为准。

## 验证集切分原则

第一版先保守：

1. 如果赛方给了官方验证集，优先使用官方划分。
2. 如果有 domain 字段，至少保留一个跨域验证切分。
3. 如果没有 domain 字段，先做 stratified split（按类别分层切分），再用图像统计特征检查分布差异。
4. 不把测试集信息泄漏进训练过程。
