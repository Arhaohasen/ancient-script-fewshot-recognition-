## 提交文件约定

本项目统一把提交文件放在：

```text
05-submission/submissions/
```

命名建议：

```text
submit_YYYYMMDD_HHMM_expNNN_shortname.csv
```

示例：

```text
submit_20260511_0130_exp001_baseline_pipeline.csv
```

## 提交前检查

- [ ] 行数与测试集样本数一致；
- [ ] `image_id` 或样本 ID 没有缺失、重复；
- [ ] 类别 ID / 标签值在允许范围内；
- [ ] 文件编码和分隔符符合赛方要求；
- [ ] 文件名能追溯到具体实验；
- [ ] `03-实验/JOURNAL.md` 已记录本次提交目的。
