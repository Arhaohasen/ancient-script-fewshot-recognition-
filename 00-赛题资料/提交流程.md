## 提交文件约定

本项目统一把提交文件放在：

```text
05-submission/submissions/
```

命名建议：

```text
submit_YYYYMMDD_HHMM_expNNN_shortname.csv
```

示例：

```text
submit_20260511_0130_exp001_baseline_pipeline.csv
```

若赛方最终要求 JSON，统一命名为：

```text
prediction_expNNN_shortname.json
```

## 编码要求

> 2026-05-21 根据赛题通知补充。

- 赛方提交文件 `prediction.json` 必须为 UTF-8 编码。
- UTF-8 可以表示全部 Unicode 字符，不需要、也不应改用 UTF-16。
- 生成 JSON 时使用 UTF-8 写文件；如使用 Python，建议 `open(path, "w", encoding="utf-8")` 并显式确认输出文件可被 `json.load` 正常读回。
- 对 `ZH-`、`None` 等无效占位标签，不应作为有效类别提交；训练和推理标签映射需在数据检查阶段统一过滤或处理。
