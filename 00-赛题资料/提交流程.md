## 镜像运行约定

赛方要求：

```text
/app/run.sh
/saisdata/
/saisresult/prediction.json
```

含义：

| 路径 | 说明 |
|---|---|
| `/app/run.sh` | 镜像启动后执行的脚本 |
| `/saisdata` | 赛方挂载的输入数据目录 |
| `/saisresult` | 参赛者写输出结果的目录 |
| `/saisresult/prediction.json` | 固定结果文件名，必须 UTF-8 |

本仓库的提交入口应保持与上述路径兼容。如果仓库内容被复制到 `/app`，根目录 `run.sh` 即为入口。

---

## `prediction.json` 结构

格式示例：

```json
{
  "ZHJWD060612-000001-GUJINGJUYING195": [
    {"bbox": [843, 2087, 93, 89], "text": "天"},
    {"bbox": [808, 2147, 97, 96], "text": "王"}
  ]
}
```

字段：

| 字段 | 说明 |
|---|---|
| 顶层 key | 图片 ID，即 `/saisdata/13/eval/images/{图片ID}.png` 的 stem |
| `bbox` | `[x, y, w, h]`，左上角坐标 + 宽高，整数 |
| `text` | 识别出的字符内容 |

## 编码要求

> 2026-05-21 根据赛题通知补充。

- 赛方提交文件 `prediction.json` 必须为 UTF-8 编码。
- UTF-8 可以表示全部 Unicode 字符，不需要、也不应改用 UTF-16。
- 生成 JSON 时使用 UTF-8 写文件；如使用 Python，建议 `open(path, "w", encoding="utf-8")` 并显式确认输出文件可被 `json.load` 正常读回。
- 对 `ZH-`、`None` 等无效占位标签，不应作为有效类别提交；训练和推理标签映射需在数据检查阶段统一过滤或处理。
