# 05-submission

这里放提交相关文件和记录。真正提交前先看 `00-赛题资料/提交流程.md`。

---

## 目录

```text
05-submission/
├── README.md
└── submissions/
```

---

## 文件命名

```text
submit_YYYYMMDD_HHMM_expNNN_shortname.csv
```

如果赛方要求 zip 或其他格式，按赛方格式补充：

```text
submit_YYYYMMDD_HHMM_expNNN_shortname.zip
```

---

## 提交后必须记录

1. 文件路径；
2. 对应实验；
3. 线上分数；
4. 与上一次提交相比的变化；
5. 下一步判断。
