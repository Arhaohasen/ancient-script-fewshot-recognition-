# 少样本学习基础

## 一句话理解

少样本学习（Few-Shot Learning）研究的是：每个类别只有很少标注样本时，模型如何仍然学会区分类别。

---

## 关键概念

| 概念 | 人话解释 |
|---|---|
| N-way K-shot | 一次任务里有 N 个类别，每类 K 个样本 |
| Support set | 少量有标签样本，模型用它来认识类别 |
| Query set | 要预测的样本，用来评估模型是否学会 |
| Prototype | 一个类别的代表向量，通常由该类样本特征平均得到 |
| Metric learning | 度量学习，让同类样本距离近、异类样本距离远 |
| Episodic training | 按少样本任务的形式训练，而不是普通分类训练 |

---

## 候选方法

### 1. 普通微调 baseline

先用预训练图像模型做分类微调，作为最低基线。

### 2. 原型网络

每个类别用一个 prototype 表示，预测时看测试样本离哪个 prototype 最近。

### 3. 对比学习

通过正负样本对学习更稳定的特征空间，适合类别相似、样本少的任务。

### 4. Adapter / Prompt 微调

冻结大部分预训练模型，只训练少量参数，降低小样本过拟合风险。

---

## 实验顺序建议

1. `exp001`：普通 supervised baseline 跑通。
2. `exp002`：加预训练模型与强数据增强。
3. `exp003`：prototype classifier。
4. `exp004`：episodic training。
5. `exp005`：对比学习或自监督预训练。

---

## 风险

- 少样本方法如果验证集设计不好，可能看起来涨分但线上不稳。
- 如果测试类别都在训练集中出现，普通分类微调可能已经很强。
- 如果测试包含新类别，普通分类头会失效，需要重新设计任务形式。
